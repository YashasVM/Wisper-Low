CLI.

Bind these to your window manager. They talk to the running instance.

--toggle-transcriptionStart or stop recording on the running instance
--toggle-post-processToggle recording with post-processing
--cancelCancel the current operation
--start-hiddenLaunch to the tray without a window
--no-trayRun without a system tray icon
--debugVerbose trace logging
