Recording
( Principles )

Built on a simple idea: your words belong to you.

01

Local, always

Whisper, Parakeet and friends run on your own CPU or GPU. Audio never touches a server — there's no server to touch.

02

Anywhere you type

One global shortcut, push-to-talk or toggle. The result is pasted straight into the app you're already using.

03

Fast by default

Metal and Vulkan acceleration, plus voice activity detection that trims silence before the model ever sees it.

04

Many languages

Multilingual models with optional translation to English, and a history of everything you've dictated.

05

Open source

Read every line. Build it yourself. Script it from the command line with flags like --toggle-transcription.
