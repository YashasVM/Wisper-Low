Legal notice for Wisperlow romanization assets
==============================================

Scope
-----

This notice covers the romanization word-pair assets built from open data by
`android/tools/indic/build_indic_pairs.py`:

- `android/app/src/main/assets/indic/hi.tsv`  (Hindi, Devanagari)
- `android/app/src/main/assets/indic/kn.tsv`  (Kannada, Kannada script)

No proprietary data was used in these assets.

License of the assets
---------------------

The assets are licensed CC0 1.0 (public domain dedication), because every
input row is from a subset of the source dataset that its publisher placed
under CC0 1.0. The full CC0 1.0 legal text is below. Provenance (source
page, train-member filename, decompressed member sha256, split, generation
command) is embedded in each TSV's `#`-comment header.

Source data
-----------

Source: Aksharantar train split (train members only; the dev/test members
of the dataset were never read, so neither file contains evaluation data).

Dataset page: https://indicnlp.ai4bharat.org/aksharantar/
Project/repository (code and models, MIT):
https://github.com/AI4Bharat/IndicXlit
Paper: Madhani et al., "Aksharantar: Towards building open transliteration
tools for the next billion users", arXiv:2205.03018, Findings of EMNLP 2023,
https://aclanthology.org/2023.findings-emnlp.4/

License declaration of the source (quoted from the paper's introduction):

  "The code and models are available under an MIT license, the Aksharantar
   benchmark and all data we created manually are available under the CCBY
   license, whereas all the mined data is available under the CC0 license."

Footnote 3 (CC BY): https://creativecommons.org/licenses/by/4.0/
Footnote 4 (CC0):   https://creativecommons.org/publicdomain/zero/1.0/

Row-level license filter used when building the assets: only rows whose
`source` field is one of the mined CC0 subsets — Wikidata, Samanantar,
IndicCorp — were accepted. Rows with `source = Dakshina` (imported
third-party data under CC BY-SA 4.0), `source = AK-Freq` and other manually
created rows (CC BY 4.0, and also evaluation-benchmark rows), and
`source = Existing` (a compilation of prior transliteration corpora whose
per-row licenses cannot be verified) were all excluded. Consequently no
CC-BY, CC BY-SA, or unverifiable-license content is shipped inside these
files, and share-alike obligations from Dakshina do not attach to them.

Attribution
-----------

CC0 imposes no attribution requirement, but crediting the source is fair and
requested by the project:

    Wisperlow romanization assets are derived from the Aksharantar
    transliteration dataset (AI4Bharat), whose mined data is released
    under CC0. https://indicnlp.ai4bharat.org/aksharantar/

If you redistribute the assets, keeping this notice and the TSV provenance
headers attached is the simplest way to satisfy both goals.

Generation
----------

Generation command (values used for the committed files):

    python3 -I android/tools/indic/build_indic_pairs.py \
        --hi-zip hin.zip \
        --kn-zip kan.zip \
        --out-dir android/app/src/main/assets/indic \
        --max-pairs 100000 --max-bytes 6000000 --split train

The zips are the Aksharantar per-language archives (aksharantar-hin.zip,
aksharantar-kan.zip) from the dataset page. The builder is deterministic:
the same inputs and flags produce byte-identical TSVs.
