Wisperlow Latin Hindi/Kannada suggestion dictionaries

Files: dict/hi_latn.tsv, dict/hi_latn_bigrams.tsv,
       dict/kn_latn.tsv, dict/kn_latn_bigrams.tsv
Modified by the Wisperlow contributors, 2026-10-17: lowercase ASCII token
filtering, explicit-content line exclusion, bounded source-line selection,
weighted and capped counts, conversational-word priority, TRAIN lexicon
membership fallback, vocabulary selection and conversational-only bigrams.
Only original input spelling is counted; normalization target columns are not.
Conversational comments are deduplicated across source files. Pairs of common
English words are excluded using the top2000 entries of the existing English
frequency asset (Hermit Dave/FrequencyWords, MIT; see its separate notice). Scores are not raw corpus frequencies or speaker preferences.
Exact input SHA-256 hashes and consumed-line counts appear in each file header.
