01The idea in 30 seconds

Wisperlow (README.md:1-3) is a cross-platform dictation app: record with a global hotkey, transcribe locally on your machine (audio never goes to a cloud transcription service), and insert the text into the active app via clipboard/paste. It starts minimized to the tray (src-tauri/src/lib.rs:963-973).

Rust backend

src-tauri/src/ — recording, models, transcription, history. Tauri 2.x, binary name handy (src-tauri/src/cli.rs:5).

React frontend

src/ — React 18 + TypeScript + Vite + Tailwind 4 + Zustand + i18next (package.json, v0.9.5).

Primary sources: README.md, AGENTS.md, package.json.

02A keypress's journey

Follow one dictation from hotkey to pasted text. This is the only diagram you need:

hotkey → TranscriptionCoordinator → AudioRecordingManager → cpal mic → resample 16 kHz → Silero VAD → stop → save .wav → TranscriptionManager → cleanup + history → clipboard paste

In code that is src-tauri/src/actions.rs + transcription_coordinator.rs: preload model & VAD in parallel → start recording → on stop, save the WAV while finalizing the stream (or batch-transcribing) → process_transcription_output() → HistoryManager::save_entry → clipboard::paste() on the main thread.

03Backend: the four managers

Created once at startup in initialize_core_logic() (src-tauri/src/lib.rs:149-183) and shared via Tauri state. Each owns one job:

Audio — managers/audio.rs

AudioRecordingManager: idle / recording / stopping states, mic open & mute, device cache, extra tail buffer, pads clips shorter than ~1.25 s.

Models — managers/model.rs

ModelManager: registry of every model (ModelInfo: id, file, engine, size, translation/streaming support). Seeds Whisper small / medium / turbo / large + ONNX families, discovers custom .bin / .gguf files, downloads via hf-hub, cancels and deletes.

Transcription — managers/transcription.rs

TranscriptionManager: loads one engine at a time, transcribe(samples) → String, live streaming via StreamRouter, idle-unloads models on a timer, emits model-state-changed.

History — managers/history.rs

HistoryManager: every dictation saves recordings/wisperlow-*.wav + a row in history.db (sqlite). Emits HistoryUpdatePayload::{Added, Updated, Deleted, Toggled}.

04Audio & voice detection

Low-level audio lives in src-tauri/src/audio_toolkit/:

  • Capture (audio/recorder.rs, audio/device.rs): cpal lists devices, opens the selected mic, downmixes channels, and rubato resamples everything to 16 kHz mono, 30 ms frames.
  • Voice activity (vad/silero.rs, vad/smoothed.rs): the Silero VAD v4 ONNX model (src-tauri/resources/models/silero_vad_v4.onnx, threshold 0.3) wrapped in a smoother with prefill/hangover, so keyboard clicks don't chop words. Policy is VadPolicy::{Disabled, Offline, Streaming} — streaming models keep VAD live.
  • Levels (audio/visualizer.rs): an FFT visualizer feeds mic-level events at ~30 fps for the overlay.

Mic modes (managers/audio.rs): AlwaysOn keeps the stream warm for instant start; OnDemand opens it per dictation. Recording only signals "ready" after the first real chunk, which hides Bluetooth/USB latency.

05Transcription engines & cleanup

Two engine families (managers/transcription.rs, Cargo.toml)

  • transcribe-cpp — Whisper-family GGML/GGUF with GPU acceleration (Metal on macOS, Vulkan elsewhere). Handles translate tasks and language selection.
  • transcribe-rs (ONNX) — Parakeet v2/v3, Moonshine (+streaming), SenseVoice, GigaAM, Canary, Cohere.

Live streaming

The recorder feeds a StreamRouter directly; the worker emits StreamTextEvent{committed, tentative} + StreamPhaseEvent{Listening, Working} to the overlay. If streaming yields nothing, it falls back to batch.

Cleanup after raw text (audio_toolkit/text.rs, actions.rs, llm_client.rs)

  • Fuzzy custom words (Levenshtein + Soundex, threshold 0.18).
  • Filler removal (uh / umm / hmm…, language-aware gating).
  • Stutter collapse + whitespace normalize; OpenCC conversion for Simplified/Traditional Chinese.
  • Optional LLM polish (OpenAI, Anthropic, Groq, OpenRouter, Bedrock, Apple Intelligence on ARM Macs).

06Frontend: React + store

src/App.tsx:31,39-80 — onboarding is accessibility → model → done; returning users skip model picking. After onboarding it calls initializeEnigo() + initializeShortcuts() and refreshes audio devices. Layout: Sidebar + HomeDashboard | settings + Footer + Toaster + WhatsNewGate.

  • Components (src/components/): ~40 settings panels (mic, language, accelerators, paste, post-processing, VAD…), model-selector/, onboarding/, overlay/RecordingOverlay.tsx, update-checker/, home/HomeDashboard.
  • State (src/stores/settingsStore.ts:1-60): Zustand + subscribeWithSelector, optimistic updateSetting → commands.*, listens for model-state-changed / settings-changed.
  • Types: src/bindings.ts is auto-generated by tauri-specta — never hand-edit it.
  • Languages (src/i18n/): English source + 20+ locales; ESLint forbids hardcoded JSX strings. Debug panel: Ctrl/⌘ + Shift + D.

08Plumbing: settings, shortcuts, tray, overlay, paste

  • Settings (settings.rs): ~50 fields in settings_store.json via tauri-plugin-store, schema-version migrations, secrets redacted, portable mode supported (portable.rs).
  • Shortcuts (shortcut/): transcribe Opt/Ctrl+Space, with post-processing Opt/Ctrl+Shift+Space, cancel Esc. Backends: Tauri (Linux default) vs HandyKeys (macOS/Windows default), plus a Carbon fallback when macOS Secure Input sticks (secure_input.rs).
  • Tray (tray.rs): Idle / Recording / Transcribing icons, model submenu, copy-last-transcript, unload model.
  • Overlay (overlay.rs): None / Minimal / Live pill (256×46) or streaming view (400×120); NSPanel on macOS, gtk-layer-shell on Linux, topmost window on Windows.
  • Paste (clipboard.rs, input.rs, paste_tx/): save/restore clipboard, paste methods (CtrlV / Direct / ShiftInsert / ExternalScript / None), typing tools (wtype / xdotool…), enigo initialized only after permissions (lib.rs:149-153).

09CLI, single instance & headless mode

Flags are defined in src-tauri/src/cli.rs:6-63 and are runtime-only (never persisted):

FlagWhat it does
--toggle-transcription / --toggle-post-process / --cancelSent to the running instance via tauri_plugin_single_instance (lib.rs:816-828), then the second process exits.
--start-hidden / --no-tray / --debugLaunch behavior + Trace logging overrides.
--transcribe-file f.wav [--model id] [--device-index N] [--repeat N] [--json]Headless one-shot: same TranscriptionManager::transcribe, no mic/VAD/download (lib.rs:401-587). WAV must be 16 kHz mono 16-bit PCM.
--list-devices / --list-modelsPrint compute devices / model registry and exit (scripts love --json).

Unix signals (signal_handle.rs): SIGUSR2 → transcribe everywhere; SIGUSR1 → post-process on macOS only (Linux reserves it for WebKitGTK).
